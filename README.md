# WorldQuest · 世界地理挑战

探索世界，挑战你的地理知识。

86 国本地题库，国旗、首都和国家线索三个模式，每局 10 题。支持答题解析、连胜积分、个人记录、成就、键盘操作及手机布局。

## GitHub Pages

这是可直接发布的静态网站目录。将此目录内容提交到公开仓库的 `main` 分支，在 **Settings → Pages → Deploy from a branch** 中选择 **main / (root)**。

所有游戏资源使用相对地址，可部署到 `https://用户名.github.io/仓库名/`。`.nojekyll` 文件用于关闭 Jekyll 处理。无需构建步骤、账号、API Key 或外部资源服务。

个人记录仅保存在当前浏览器。不同域名和设备之间不自动同步。

## 数据与资源

- 国家数据：https://github.com/mledoze/countries ，本地整理版本为 `countries.json`，按 ODbL 授权，详见 `data-license.txt`。
- 国旗：https://flagcdn.com/ ，本地 SVG 文件位于 `flags/`。
- 装饰地图：Natural Earth 公共领域陆地数据。
